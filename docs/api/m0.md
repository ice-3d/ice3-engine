# ICE3 M0 公开 API

> Document ID: ICE3-ENG-API-001
>
> Status: Active
>
> Owner: ICE3 Engine maintainers
`ice3` package 是唯一受支持的消费入口。M0 提供聚焦于 Scene rendering 和 2D/3D
composition 的 API。

## 完整示例

```ts
import {
  ICE3,
  ICEBasicMaterial,
  ICEBoxGeometry,
  ICELabel,
  ICEMesh,
  ICEOrbitController,
  ICEPerspectiveCamera,
  ICEScene,
  ICEScreenLayer,
  ICEWorldLayer,
} from 'ice3';

const host = document.querySelector<HTMLElement>('#stage');
if (!host) throw new Error('Missing stage');

const engine = new ICE3().init(host);
const scene = new ICEScene({ id: 'scene' });
const camera = new ICEPerspectiveCamera({
  id: 'camera',
  fov: 45,
  near: 0.1,
  far: 100,
  position: [3, 2, 5],
  target: [0, 0, 0],
});

const block = new ICEMesh({
  id: 'block',
  geometry: new ICEBoxGeometry({ width: 1, height: 1, depth: 1 }),
  material: new ICEBasicMaterial({
    color: '#2f81f7',
    edgeColor: '#e6f2ff',
  }),
});
scene.addChild(block);

const worldLayer = new ICEWorldLayer({ id: 'world', order: 0 });
worldLayer.addChild(
  new ICELabel({ id: 'block-label', text: 'Block', anchorId: 'block' }),
);

const hudLayer = new ICEScreenLayer({ id: 'hud', order: 10 });
hudLayer.addChild(
  new ICELabel({
    id: 'status',
    text: 'Running',
    screenPosition: [24, 24],
    interactive: true,
  }),
);

const orbit = new ICEOrbitController(engine, camera).start();
engine
  .setScene(scene)
  .setCamera(camera)
  .addLayer(worldLayer)
  .addLayer(hudLayer)
  .start();

// 释放所有 frame request、DOM listener、layer 和 GPU resource。
orbit.dispose();
engine.destroy();
```

## Engine

### `new ICE3(options?)`

创建 Engine instance。

选项：

- `backend`：注入 Renderer backend；production 默认使用 WebGL2 backend。
- `scheduler`：注入 frame scheduler；production 默认使用 browser frame scheduler。

### `init(target)`

绑定 `HTMLElement`、Canvas element 或 selector。方法创建或配置 Scene canvas 和透明 2D
overlay，初始化 backend 并应用当前 viewport。

只能调用一次。重复初始化会以 `ICE3_ALREADY_INITIALIZED` 失败。

### `setScene(scene)` and `setCamera(camera)`

设置 active Scene 和 PerspectiveCamera。两者都设置前 Engine 不渲染。

### `addLayer(layer)` and `removeLayer(layer)`

添加或移除 layer。较小的 `order` 先绘制；相同 order 保持插入顺序，后插入的 layer
优先参与 hit test。

### `start()`, `stop()`, and `requestRender(reason?)`

`start()` 幂等，并启用 on-demand rendering。`requestRender()` 将请求合并为一个 pending
frame。`stop()` 取消 pending work，不销毁 resource。

### `project(position)`

将 world position 转换为相对于 3D viewport 的 CSS pixel。

返回 `{ x, y, visible, depth }`。

### `getSelection()` and `setSelection(ids)`

读取或替换共享 semantic Selection set。Selection 变化时发送 `SELECTION_CHANGE`。

Selection 在短点击释放时提交，不在 pointer down 时提交。移动不超过四个 CSS pixel
仍视为 click；更长的 pointer 路径视为 camera drag，即使 pointer 返回起点。交互式 2D
control 不触发或清除 3D Selection。

### `pick(point)`

返回 viewport point 下最近的可见 Scene Node。结果使用与 Selection 和 2D label 相同的
稳定 Node identity。

Active backend 支持 exact picking 时，`pick()` 渲染 offscreen identity image，并读取
指定 pixel 处的可见表面。不具备该能力的测试 backend 使用 semantic fallback。

### `getDiagnostics()`

返回 frame ID、FPS、CPU frame time、backend capability、Scene/Layer count、DPR、
viewport、context-loss count、label rectangle 和最近 Diagnostic。它不暴露 Canvas、
WebGL 或 painter object。

### `resize()` and `destroy()`

`resize()` 重新计算 host viewport 和 DPR。`destroy()` 幂等，并释放 scheduled frame、
input listener、layer、generated canvas 和 renderer resource。

## Scene model

### `ICENode`

接受 `{ id, position?, rotation?, scale? }`。Node 管理稳定 ID、parent/child link、
visibility、transform、event listener 和 JSON serialization。

重复 ID、Scene cycle 和无效 ID 会被拒绝。

### `ICEScene`

Scene root，type ID 为 `ice3:Scene`。

### `ICEMesh`

将稳定 Node ID 与 `ICEBoxGeometry`、`ICEBasicMaterial` 组合。

### `ICEBoxGeometry`

接受正数 `width`、`height` 和 `depth`。Type ID 为 `ice3:BoxGeometry`。

### `ICEBasicMaterial`

接受 CSS hexadecimal base color 和可选 `edgeColor`。默认使用 unlit rendering，因此
Geometry 颜色保持一致；`edgeColor` 增加高对比 Geometry outline。Type ID 为
`ice3:BasicMaterial`。

### `ICEPerspectiveCamera`

接受 `id`、`fov`、`near`、`far`、`position` 和可选 `target`。使用 `setPosition()`
与 `setTarget()` 更新 camera。

## 2D layer

### `ICEWorldLayer`

绘制锚定到 Scene ID 的 label。Anchor 缺失时 label 不可见，并产生
`ICE3_UNKNOWN_ANCHOR`。

### `ICEScreenLayer`

在明确 screen position 绘制 label。

### `ICELabel`

接受 `id`、`text` 以及 `anchorId` 或 `screenPosition`。可选字段为 `color`、
`background`、`padding` 和 `interactive`。

## 交互

### `ICEOrbitController`

`start()` 订阅共享 Engine event；`stop()` 释放订阅；`dispose()` 永久关闭 controller。

从 Geometry 或空白 3D 区域开始拖拽会启动带阻尼的 orbit。Wheel 和 pinch zoom 同样
带阻尼。交互式 2D label 消费手势，不启动 camera orbit。WASD 和对应 arrow key 沿 view
plane 平移 camera 及其 target，不改变 zoom distance；松开按键即停止移动。Editable
control 保留正常 keyboard input。

## 序列化与注册

- `serializeScene(scene)` 创建 schema version 1 Scene snapshot。
- `deserializeScene(snapshot, registry)` 返回恢复后的 Scene 和结构化 error。
- `ICETypeRegistry.register(typeId, type)` 强制 type ID 和 constructor 唯一。

## Error 与类型

- `ICEEngineError` 携带稳定 `code`、message、可选 details 和可选 Diagnostic。
- `ICEDiagnostic` 包含 severity、code、message、path 和 details。
- `ICEEngineDiagnostics` 是 `getDiagnostics()` 返回的只读 Diagnostic snapshot。
