# ICE3 M1 Asset API

> Document ID: ICE3-ENG-API-002
>
> Status: Active
>
> Owner: ICE3 Engine maintainers
`ice3` 仍是唯一受支持的公开入口。M1 增加加载由 `ice3-toolchain` 生成的
`ICE3 Prepared GLB Profile v1` 文件。

## 完整示例

```ts
import {
  ICE3,
  ICEOrbitController,
  ICEPerspectiveCamera,
  ICETilesetLoader,
} from 'ice3';

const host = document.querySelector<HTMLElement>('#stage');
if (!host) throw new Error('Missing stage');

const engine = new ICE3().init(host);
engine.setBackgroundColor('#000000');
const camera = new ICEPerspectiveCamera({
  id: 'camera',
  fov: 45,
  near: 0.1,
  far: 1000,
  position: [3, 2, 5],
  target: [0, 0, 0],
});
const orbit = new ICEOrbitController(engine, camera).start();
const tileset = await new ICETilesetLoader(engine, { camera }).open(
  '/assets/partitioned/tileset.json',
);

engine
  .setScene(tileset.scene)
  .setCamera(camera)
  .start();

await tileset.whenReady();
// Continue working while remaining partitions load.
await tileset.whenIdle();

// Idempotently detach and dispose every loaded partition.
tileset.dispose();
orbit.dispose();
engine.destroy();
```

### Camera 控制

示例 camera 支持拖拽旋转、wheel zoom 和 keyboard movement。按住 WASD 或对应 arrow
key，可沿 view plane 平移且不改变 zoom distance；按键按住时持续移动，松开即停止。
Example 加载后在左下角保留紧凑 control hint，不拦截 pointer input。

Prepared Asset 中，一个具名 Mesh Node 就是一个可选 equipment unit。同一 source Node
的多个 primitive 共享一个 Selection identity。短点击可见 Geometry 会选中设备并应用
黄色 highlight，不修改 source Material。Example 在右上角固定 panel 中显示选中设备
详情，不在模型上叠加 label。缺少业务字段时使用确定性演示数据。点击空白区域清除
Selection。

### 加载反馈

Scene 就绪前，example 渲染覆盖整个 stage 的 loading overlay。Overlay 使用
`role="status"`，更新 stage 的 `aria-busy` state，在加载中锁定 Asset disposal，首次
渲染后淡出，并在加载失败时保持明确 error state。

### `engine.setBackgroundColor(color)`

使用 hexadecimal color 设置 WebGL Scene clear color。默认仍是 M0 的深色工程画布。
M1 Asset example 使用黑色，让 Asset 自身 display color 成为主要视觉分隔手段。

## `ICEAssetLoader`

```ts
new ICEAssetLoader(engine, options?)
```

选项：

- `fetch`：自定义 request implementation，production 默认使用 `globalThis.fetch`。
- `verifyIntegrity`：为 `true` 时对 BIN chunk 执行一次 SHA-256 扫描。默认 `false`，
  避免正常加载期间重复读取大 buffer。

### `load(url, options?)`

返回 `Promise<ICEAssetHandle>`。

- `options.signal`：可选 `AbortSignal`。
- 同一 URL 的 concurrent load 共享不可变 decoded bytes。
- 每次成功调用创建独立 Scene instance。
- 失败或取消的 request 不进入 reusable cache。

### `clear()`

清除缓存的不可变 Asset bytes。已存在 Scene handle 不受影响。

## `ICEAssetHandle`

```ts
{
  id: string;
  scene: ICEScene;
  bounds: {
    min: [number, number, number];
    max: [number, number, number];
  };
  stats: {
    nodeCount: number;
    maxNodeDepth: number;
    meshCount: number;
    primitiveCount: number;
    triangleCount: number;
    edgeSegmentCount: number;
    materialCount: number;
    selectionGroupCount: number;
  };
  contract: {
    status: 'active' | 'legacy';
    version?: string;
    preparation?: Record<string, unknown>;
    budget?: {
      profile: string;
      status: 'pass' | 'warning' | 'error';
      warningCount: number;
      errorCount: number;
    };
  };
  dispose(): void;
}
```

`dispose()` 幂等。它释放已加载 Scene tree，并请求一帧，让 Renderer 释放不再引用的
Geometry buffer。

缺少共享 contract 的旧 prepared Asset 使用 `contract.status` = `legacy`。Engine
对这些 Asset 发出 warning，并根据实际 GLB 结构填充缺失统计。

## `ICETilesetLoader`

```ts
new ICETilesetLoader(engine, {
  fetch,
  camera,
  maxConcurrentTiles: 2,
  maxResidentTiles: 24,
  maxResidentBytes: 268435456,
  prefetchMarginRatio: 0.10,
  unloadMarginRatio: 0.20,
  maxCommitsPerFrame: 1,
  maxScreenSpaceErrorPixels: 16,
});
```

选项：

- `fetch`：自定义 request implementation。
- `camera`：计算 visible work set 所需的 camera。
- `maxConcurrentTiles`：正数 request concurrency，默认 `2`。
- `maxResidentTiles`：soft resident partition limit，默认 `24`。
- `maxResidentBytes`：soft resident Geometry byte limit，默认 `256 MiB`。
- `prefetchMarginRatio`：相对 Scene radius 的 preload frustum expansion，默认 `0.10`。
- `unloadMarginRatio`：相对 Scene radius 的 unload frustum expansion，默认 `0.20`，
  且必须大于 prefetch ratio。
- `maxCommitsPerFrame`：每帧最多向 Scene 提交的完成 partition 数，默认 `1`。
- `maxScreenSpaceErrorPixels`：visible LOD Node refine 前的最大 screen-space error，
  默认 `16` pixel，且必须为正数。

默认值在受控工业 Asset 上使用 `16`、`32` 和 `48` pixel 校准。`32` 和 `48` 产生相同
overview 与 focused cut；`16` 在 resident byte budget 内保留更多 overview detail，
且不改变 focused equipment cut。应用可根据 Geometry 和交互距离覆盖该值。

### `open(url, options?)`

获取并校验 `tileset.json`，创建空 unified Scene，启动 partition loading，并在不等待全部
Tile content 的情况下返回 `Promise<ICETilesetHandle>`。相对 Tileset URL 按当前页面
解析。`options.signal` 取消 index request 和 pending partition request。

### `ICETilesetHandle`

```ts
{
  scene: ICEScene;
  bounds: ICEGeometryBounds;
  stats: {
    total: number;
    pending: number;
    loading: number;
    loaded: number;
    failed: number;
    evicted: number;
    visible: number;
    resident: number;
    residentBytes: number;
    lod: {
      target: number;
      resident: number;
      coarseResident: number;
      fineResident: number;
      transitioning: number;
      fallback: number;
      maxScreenSpaceErrorPixels: number;
    };
  };
  tileState(tileId: string): 'pending' | 'loading' | 'loaded' | 'failed' | 'evicted' | undefined;
  whenReady(): Promise<void>;
  whenIdle(): Promise<void>;
  dispose(): void;
}
```

`whenReady()` 在首个 partition commit 后 resolve。若首个失败 partition 在任何成功前
settle，则 reject，同时其他 concurrent partition 继续。`whenIdle()` 在当前 work set
没有 pending、loading 或 waiting-to-commit partition 时 settle。它观察调用时捕获的
work set；后续 camera 变化形成新 work-set cycle，不延长之前的 `whenIdle()`。

`whenComplete()` 有意不提供。Camera-driven Tileset 不承诺让所有 partition 保持
resident，全局 completion promise 会表达错误的 lifecycle。

每个 Tile 具有以下状态之一：

- `pending`：当前 work set 需要，但尚未 request。
- `loading`：已 request 或正在准备 Scene commit。
- `loaded`：已提交到 unified Scene 且 resident。
- `failed`：当前尝试失败。
- `evicted`：位于 retention set 外、commit 前丢弃或已释放。

Handle 发送：

- `TILESET_TILE_LOADING`
- `TILESET_TILE_LOADED`
- `TILESET_TILE_FAILED`
- `TILESET_TILE_UNLOADED`
- `TILESET_READY`
- `TILESET_IDLE`
- `TILESET_LOD_CHANGED`
- `TILESET_LOD_FALLBACK`

每个 event parameter 包含不可变 `stats` snapshot；Tile 专用 event 还包含 `tileId`。
Partition 失败时保留之前加载的 partition，并报告 `ICE3_TILESET_TILE_FAILED`。位于
unload frustum 外的 partition 从 unified Scene 原子移除，并释放 decoded cache entry。
Replacement content 仍携带同一 semantic Selection ID 时继续保留 Selection；只有该
identity 离开 resident Scene 时才清除。`TILESET_IDLE` 报告当前 work set 已 settle。

### 支持的 Tileset 子集

- 3D Tiles 1.1 `asset.version`。
- 显式 `children` tree。
- 本地 Cartesian `box` 或 `sphere` Bounds。
- 指向 ICE3 Prepared GLB 的相对 `content.uri`。
- internal `REPLACE` Node 上的 parent content。
- 有限 4x4 `transform`。
- `REPLACE` refinement。

`region`、外部 Tileset、`implicitTiling`、不支持的 content 和未声明 required extension
会以 `ICE3_TILESET_UNSUPPORTED` 失败。

Visible partition 始终优先于 resident budget。Visible set 超过 soft budget 时产生
warning，但不移除可见设备。超出 budget 时暂停 offscreen prefetch。`residentBytes`
是 resident partition 的 prepared position、index、edge 和 color buffer 总和，属于
明确的 Geometry byte 估算，不是 GPU driver memory report。

Loader 监听渲染后的 camera 和 viewport 变化，仅在 view-projection matrix 或 viewport
变化时重算 work set；request 按 visible status 和 distance 排序，stale candidate 在进入
Scene 前丢弃。Partition 始终包装在可移除 container 中，包括 identity-transform Tile，
因此 unload 不会移除 sibling Geometry。

Runtime 通过 `geometricError` 和 screen-space error 选择 hierarchical LOD content。
Replacement fine content commit 前，最近的 resident coarse ancestor 保持可见。
`dispose()` 恰好一次释放所有 resident partition 和完整 unified Scene。

本版本仍不包含 implicit tiling、external Tileset、texture pipeline 和 Runtime Mesh
simplification。

## Hierarchical LOD Asset 准备

Toolchain 生成本 Runtime 使用的 hierarchical LOD content：

- `parts/part-NNN.glb` 包含 fine leaf content。
- `coarse/<partition-id>.glb` 包含 internal-node proxy。
- 每个输出都是 OGC 3D Tiles 1.1 `REPLACE` Tile。
- Coarse proxy 使用每层唯一 Scene Node ID，同时保留稳定 semantic Selection ID。
- `geometricError` 记录实测 world-space simplification error。

Prepared GLB Node 可同时携带两个 identity：

```json
{
  "extras": {
    "ice3": {
      "id": "asset:lod:group-root/node/4",
      "selectionId": "asset/node/4"
    }
  }
}
```

`selectionId` 在磁盘上可选，既有 Asset 默认回退到 `id`。Mesh simplification、edge
regeneration、temporary Geometry storage 和 LOD generation 只在 Toolchain 中运行。
浏览器不链接 simplifier。

## Chunked Tileset 与 semantic query

- Internal Tile 可以暴露标准 3D Tiles `contents` array。
- 一个 logical Tile 的所有 chunk 一起 staging，并只 commit 一次。
- `residentContents` 和 `loadingContents` 报告实际 GLB residency。
- 相邻但不可见的 LOD content 以低于 visible 的优先级预取，不延长当前 cut 的
  `whenIdle()`。
- `queryScene()` 返回按 `selectionId` 去重的确定性 semantic item snapshot。
- `findBySelectionId()`、`pickItem()`、`raycast()` 和
  `ICEOrbitController.focus()` 提供通用空间交互。

这些 API 是通用 Engine capability，不包含 caller-specific concept。

## GPU residency 与稳定 transition

CPU residency、frustum visibility 和 GPU residency 是独立 state。Retained Tile 在
实际 unload 前拥有自己的 Geometry buffer。暂时隐藏 Tile、旋转到视野外或等待新 LOD
cut 都不会删除其 GPU Geometry。

默认 retention halo 覆盖完整 Asset radius，因此 camera movement 本身不会 unload
Tile；64 Tile 和 768 MiB resident budget 决定 offscreen content 何时离开。20% prefetch
会在 upcoming content 进入 strict view 前开始加载。

Camera motion 期间更新 spatial visibility。无关 Tile 的 resident、GPU-ready content
进入 retention coverage 后立即可见。Ancestor/descendant LOD replacement 延迟到
camera settle 且完整 replacement coverage 就绪，避免 coarse/fine representation
重叠或切换时出现缺口。

有意不属于 resident Tile 的 Geometry 保留 60 个 inactive frame 供复用。768 MiB
Geometry budget 优先驱逐最近最少使用且未 pinned 的 entry。新 Tile 在隐藏状态下上传，
完整 Geometry 集 GPU-ready 后才可见。Camera motion 期间保持当前完整 coverage，直到
下一 coverage 就绪。

Renderer Diagnostic 在 `gpuBytes` 旁包含累计 `gpuUploads` 和 `gpuEvictions`。同一 Tile
保持 resident 时，稳定旋转不应增加任一 counter。

## 可选 adaptive render batch

Tileset 默认使用 Prepared GLB batch。调用方可以启用 idle-time Worker repacking，而不
改变 Scene、Selection 或 Tileset API：

```ts
const loader = new ICETilesetLoader(engine, {
  camera,
  renderBatching: {
    mode: 'adaptive',
    maxWorkers: 2,
    idleTaskBudgetMs: 4,
    uploadBytesPerFrame: 2 * 1024 * 1024,
    maxExtraGpuBytes: 32 * 1024 * 1024,
  },
});
```

`asset` 是默认值。只有 camera 和 visible work set settle 后才开始 adaptive planning。
Camera motion、target change 和 disposal 会取消 candidate，同时 active generation
保持可用。Worker output 使用 Transferable `ArrayBuffer`；candidate upload 按 frame
byte budget 拆分，只有全部 candidate Geometry 就绪后才交换 Scene。

`ICETilesetHandle.adaptiveStats` 报告 mode、active generation、可选 candidate
generation 和当前 adaptive batch count。稳定 Diagnostic code 见
[diagnostics.md](../diagnostics.md)。

## Profile 边界

Loader 只接受携带以下信息的 GLB：

```json
{
  "asset": {
    "extras": {
      "ice3": {
        "profile": "ice3-prepared",
        "profileVersion": "1.0"
      }
    }
  }
}
```

Profile 要求 matrix Node transform、triangle/line primitive、非 normalized float
position、unsigned scalar index、一个 BIN chunk，且没有 external resource。Animation、
skin、Morph target、texture、image、camera、light、sparse accessor 和 required
extension 都会被拒绝。

普通 GLB 必须先由 `ice3-toolchain` 处理。Browser Runtime 不支持导入 Toolchain 或
source-format adapter。

## 通用 Geometry

`ICEIndexedGeometry` 暴露 prepared position、triangle-index 和可选 edge-index array。
`ICEMesh` 接受 `ICEBoxGeometry` 或 `ICEIndexedGeometry`。

```ts
import { ICEIndexedGeometry } from 'ice3';

const geometry = new ICEIndexedGeometry({
  id: 'triangle',
  positions: new Float32Array([0, 0, 0, 1, 0, 0, 0, 1, 0]),
  indices: new Uint16Array([0, 1, 2]),
});
```
