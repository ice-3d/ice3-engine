# ICE3 设备选择设计规格

| 项目 | 内容 |
| --- | --- |
| 状态 | 待用户评审 |
| 版本 | 1.0 |
| 日期 | 2026-10-27 |
| 范围 | `ice3-engine` 的 M1 设备级单选能力 |
| 上游约束 | M0 设计规格、M1 资产设计规格、工作区资产保护规则 |

## 1. 目标

为工业场景增加稳定、精确的设备级选择能力。用户短点击模型后选中整台设备，视觉上能够明确识别当前设备，并通过统一选择事件把设备身份交给上层应用。

第一版聚焦一条完整闭环：

1. 鼠标短点击可见设备表面。
2. GPU 拾取返回该表面所属的设备身份。
3. 引擎更新唯一选择集并触发 `SELECTION_CHANGE`。
4. 渲染层突出选中设备，不修改原始材质。
5. 示例页面显示设备名称并保持操作提示、状态栏和 2D 控件可用。

## 2. 非目标

第一版不包含：

- 零部件级下钻。
- 多选、框选或范围选择。
- 悬浮预览和鼠标指针形状跟随。
- 设备运行状态、告警、点位或业务属性。
- 对真实客户模型进行自动语义聚类。
- 修改工具链资产格式。
- 运行时解析源模型格式。
- 编辑设备层级或持久化选择结果。

## 3. 选择边界

### 3.1 设备单元

第一版将一个包含网格的命名场景节点定义为一台设备。

- 选中身份使用设备的稳定节点身份。
- 同一节点派生出的多个渲染图元共享设备身份，点击任意图元都选中整台设备。
- 程序化创建且未声明设备身份的网格，以网格自身稳定身份作为选择单元。
- 节点显示名称来自预处理资产中的原始节点名称；缺少名称时回退到稳定身份。

### 3.2 单选规则

- 新选择替换旧选择。
- 点击空白区域清空选择。
- 点击透明 2D 区域后继续传递到 3D。
- 点击可交互 2D 控件不触发 3D 选择。
- 操作提示保持 `pointer-events: none`，作为纯视觉信息允许点击穿透；其下方设备可以被选择。
- 拖拽旋转、滚轮缩放和键盘平移不改变选择。

## 4. 公共数据契约

### 4.1 场景节点显示名称

`ICENodeOptions` 增加可选 `displayName`，`ICENode` 暴露只读 `displayName`。未提供时使用稳定 `id`。

约束：

- `displayName` 只用于人类可读展示。
- 选择、拾取、锚点和事件始终使用稳定 `id`。
- 序列化保留 `displayName`，反序列化缺失时回退为 `id`。

### 4.2 设备身份

`ICEMeshOptions` 增加可选 `selectionId`，`ICEMesh` 暴露只读 `selectionId`。

- 未提供时，选择身份默认为网格自身 `id`。
- 资产构建器把同一源节点生成的网格和附加图元设置为同一 `selectionId`。
- 第一版要求 `selectionId` 能解析到场景中的设备节点，以便显示名称和锚定标签。

### 4.3 选择帧

渲染帧增加只读 `selection` 字段，内容为当前选中设备的稳定身份。渲染层通过该字段判断设备是否高亮，不读取业务状态，也不反向修改场景对象。

## 5. GPU 拾取

### 5.1 后端契约

渲染后端增加可选同步拾取方法：

```ts
pick(frame: ICEFrame, point: ICEScreenPoint): string | undefined;
```

公共类型只返回设备身份，不暴露帧缓冲、纹理、着色器或其他 GPU 对象。

`ICE3.pick(point)` 在活动 WebGL2 后端上优先使用 GPU 拾取。没有 GPU 拾取能力的测试后端可以继续使用现有语义拾取实现；生产 WebGL2 路径不会静默回退到包围盒近似结果。

### 5.2 拾取流程

1. 按当前场景、相机和视口收集可渲染网格。
2. 为每个唯一的 `selectionId` 分配从 1 开始的临时编号。
3. 将离屏 RGBA8 颜色附件清零，编号 0 表示空白。
4. 使用独立拾取着色器，仅渲染三角形表面，不渲染边线。
5. 将编号编码到颜色通道，深度测试保证只保留最前方可见表面。
6. 根据设备像素坐标和 DPR 读取一个 RGBA 像素并解码编号。
7. 把编号映射回 `selectionId`。
8. 恢复默认帧缓冲、视口和必要的 WebGL 状态。

### 5.3 资源生命周期

- 拾取帧缓冲在首次拾取时惰性创建。
- 颜色纹理和深度缓冲尺寸与当前绘图缓冲一致。
- 窗口或 DPR 变化时按需重建拾取资源。
- WebGL 上下文丢失时丢弃拾取资源，恢复后重新创建。
- 引擎销毁时释放拾取着色器、帧缓冲、纹理和深度缓冲。

### 5.4 限制与错误

- RGBA8 拾取最多支持 16,777,214 个同时可选择的唯一设备；超过限制时拒绝拾取并产生诊断。
- 拾取资源创建或帧缓冲不完整时返回空结果，产生 `ICE3_PICK_UNAVAILABLE` 诊断。
- 拾取失败不得影响场景正常渲染、相机交互或已有选择。
- 不可见节点不参与拾取。

## 6. 点击识别

选择与相机拖拽必须分离：

- 指针按下时记录起点、指针身份和命中的 2D 层级。
- 指针移动超过 4 CSS 像素后标记为拖拽。
- 指针抬起时，只有未形成拖拽且起点不属于可交互 2D 控件时才执行拾取。
- 无交互的视觉提示不捕获指针，因此起点仍按其下方场景处理。
- 指针取消或窗口失焦时不触发选择。
- 拾取使用抬起点或短点击最后位置，像素坐标按 DPR 换算。

相机旋转仍在指针按下后立即开始，不等待选择完成。

## 7. 选中效果

### 7.1 3D 效果

选择高亮在正常场景绘制后增加一个独立通道：

- 对当前选中设备再次绘制三角形，使用低透明度青色提亮。
- 使用深度测试，保持其他设备对选中设备的正常遮挡。
- 对选中设备绘制更明显的青色几何边线。
- 不修改 `ICEBasicMaterial`，不重建几何，不复制 GPU 缓冲。
- 清除选择后只恢复正常帧，不执行材质恢复逻辑。

选中色使用 M1 现有强调色 `#63d7ff`。表面提亮透明度约为 16%，仅作为辅助识别，轮廓和边线承担主要识别作用。

### 7.2 2D 标签

示例页面在设备投影位置附近显示名称标签：

- 标签文本使用 `displayName`。
- 标签位于设备屏幕中心上方，并保持在视口内。
- 选择变化时替换标签文本，不重复创建图层。
- 清除选择、释放资产或加载失败时隐藏标签。
- 标签仅用于展示，不消费指针输入。

`ICELabel` 增加 `setText(text)`，使示例可以更新已有标签而无需重建图层。

## 8. 运行时数据流

```text
pointer down
  -> input router captures scene or 2D target
  -> orbit controller may begin camera rotation

pointer up without drag
  -> engine asks renderer for selection id at pixel
  -> selection id resolves to equipment node
  -> ICEInteractionState replaces selection
  -> SELECTION_CHANGE emitted
  -> render request with selection state
  -> selected overlay and 2D label update
```

渲染器和工具链不知道业务设备类型；示例和未来应用通过稳定设备身份接入业务数据。

## 9. 诊断与可观测性

引擎诊断增加：

- `selectionCount`
- `lastPickTimeMs`
- `lastPickId`
- 拾取不可用或设备数量超限时更新 `lastDiagnostic`

这些字段只提供运行时可观测性，不构成面向 Agent 的专用接口。

## 10. 测试策略

### 10.1 单元测试

- 未声明 `selectionId` 的网格使用自身 `id`。
- 同一设备的多个网格具有相同选择身份。
- 选择集去重并稳定触发 `SELECTION_CHANGE`。
- `displayName` 缺失时回退为稳定 `id`。
- RGBA8 编号编码与解码覆盖 0、1、255、256 和上限边界。
- 渲染帧携带当前选择状态。
- 标签更新文本后尺寸和位置重新计算。

### 10.2 集成测试

- 两个前后重叠的设备只选中前方设备。
- 同一设备多个图元中的任意表面都返回同一设备身份。
- 点击空白区域清空选择。
- 拖拽超过阈值不改变选择。
- 可交互 2D 控件拦截选择。
- WebGL 上下文恢复后拾取仍可用。

### 10.3 浏览器测试

- 短点击设备后状态栏和标签显示设备名称。
- 选中设备出现青色轮廓和表面提亮。
- 重新点击空白后高亮和标签消失。
- 拖拽旋转不产生误选。
- 操作提示和窄屏布局保持可用。
- Chromium 与 WebKit 结果一致。

### 10.4 性能检查

- 使用合成多设备资产记录拾取耗时。
- 拾取只在点击时进行，常态帧率不因拾取通道下降。
- 离屏拾取资源不随每次点击重复分配。

## 11. 验收标准

第一版完成时：

1. 用户短点击任意可见设备表面即可选中整台设备。
2. 相机拖拽、缩放、键盘平移和 2D 控件操作不会误选设备。
3. 选中设备显示明显但不破坏原始颜色的青色几何高亮。
4. 设备名称标签跟随相机正确显示。
5. 点击空白清除选择。
6. 拾取结果通过统一选择集和 `SELECTION_CHANGE` 暴露。
7. 完整单元、集成、Chromium 和 WebKit 测试通过。
8. 发布包不包含真实客户模型资产或其派生文件。

## 12. 实施边界

第一版预计涉及：

- `@ice3/core`：显示名称、选择身份和序列化契约。
- `@ice3/renderer`：拾取接口、离屏拾取、选择高亮和资源生命周期。
- `@ice3/runtime`：点击判定、选择更新、帧选择状态和诊断。
- `ice3`：必要的公共类型导出。
- M1 示例：设备名称标签、状态与操作提示协同。

不修改工具链格式。模型预处理仍负责产生稳定的节点身份和名称，运行时只消费已经准备好的资产。
