# 方向光阴影：视锥拟合、路径覆盖与调试通道

> Document ID: ICE3-ENG-SPEC-008
>
> Status: Implemented
>
> Owner: ICE3 Engine maintainers

## 1. 为什么之前是关着的

`WebGL2RendererBackend` 里 `shadowEnabled` 曾经是写死的 `false`，注释写着「定位掉深度
偏差之前保持关闭」。原因不是没想到，而是三个问题叠在一起：

1. **只画一条几何路径**：阴影 pass 只遍历实例化批次。厂区的瓦片走渲染批次、单独编辑的
   物件走单体路径，两者都不进深度图——画面表现为「只有一部分设备有影子」。
2. **视锥写死**：正交视锥固定成 860 米见方、深度 `-260..700`。2048 的深度图摊到 860 米，
   每纹素 0.42 米（薄墙、栏杆的影子直接消失）；深度偏差 0.0015 在 960 米跨度上等于
   1.4 米，短影子被整段吃掉。
3. **只能靠改常量调参**：看一次效果要重编译一次，对比"有影子/没影子"要改代码。

## 2. 三条几何路径

阴影 pass 现在与相机深度通道、主通道取同一批对象：

| 路径 | 来源 | 矩阵 |
|---|---|---|
| 实例化批次 | 几何+材质重复 ≥2 次 | 顶点着色器里的实例矩阵 |
| 渲染批次 | 瓦片集（`ICERenderBatch`） | `lightVP × world` |
| 单体网格 | 落单的、编辑中的物件 | `lightVP × world` |

`WebGL2ShadowMap` 的顶点着色器因此多了一个 `u_useInstancing` 与 `u_matrix`：
实例化时矩阵是 `lightVP`、顶点自带实例变换；非实例化时矩阵是 `lightVP × world`、
顶点直接当世界坐标。两条路径共用同一个程序，切的是 uniform 而不是管线。

落单网格的集合由 `renderablesOutsideInstanceBatches`（见 SPEC-007 5.1）统一给出，
避免两个 pass 各自维护一份"哪些东西要单独画"的判断。

## 3. 视锥贴合场景

`ShadowFrustum` 按场景包围盒拟合正交投影：

1. `SceneBounds.accumulateSceneBounds` 累加每个网格的世界包围盒。几何局部包围盒按
   `WeakMap` 缓存——按帧扫顶点是不可接受的；
2. 相机放在包围盒中心沿光方向退开两倍半径处，`lookAt` 到中心；
3. 八个角投到视图空间，取紧贴的 x/y/z 范围作为视锥，四周留 8% 余量；
4. 顺带算出**一个纹素在世界空间的边长**，交给着色器做法线偏移量。

空场景回退到覆盖 600 米场地的默认盒：阴影是可选效果，宁可保守覆盖也不要整帧失败。

## 4. 偏差与法线偏移

只靠深度偏差追平误差是错的方向——偏差大了影子脱离物体（peter-panning），小了长痤疮。
这里两条一起用：

- **法线偏移**：比较点沿法线推出 1.5 个纹素再投影。平躺的面（屋顶、地面）在每个纹素
  区间内自身就有深度差，抬离表面才是正解；偏移量按纹素换算，与场景尺度解耦。
- **深度偏差**：`0.0006 + 0.0012 × (1 - N·L)`。视锥贴合后深度跨度只有百米量级，
  偏差换算成世界尺度是厘米级——这是旧实现做不到的。

阴影 pass 不做面剔除。剔除依赖顶点绕序，导入模型绕序不统一时会静默失效（看起来像
"某些模型没有影子"），代价是深度图记的是离光最近的一层，靠法线偏移压住自阴影。

## 5. 开关与调试通道

| 入口 | 作用 |
|---|---|
| `initialize({ shadows: true })` | 代码里开关；默认关闭（一次额外全场景 pass） |
| `?shadows=1` / `?shadows=0` | 地址栏开关，和 `?ao` 同属调参通道 |
| `?shadowdebug=1` | 输出遮蔽判定：受光 / 被遮二值图 |
| `?shadowdebug=2` | 输出深度图本身 |

调试通道是排查阴影的唯一可信手段。AO 那三轮的经验已经证明：看不见中间量的时候，
任何"调参"都是在猜。判定图能一眼分清三类问题——路径没画（整片受光）、视锥裁掉
（边缘一条直边）、偏差不对（物体表面出现整块暗斑）。

## 6. 验收

固定机位（厂区全景、SwiftShader、1440×900），同一次运行内切换 `?shadows`：

| 状态 | 平均亮度 | 高光像素 | 变化像素 |
|---|---|---|---|
| 关闭 | 95.70 | 878 | — |
| 开启 | 93.27 | 487 | 0.35%（约 4.5k 像素，集中在构筑物背光侧与墙脚） |

判定图上，地面与屋顶整体保持受光，暗区沿光方向贴在墙脚与背光面——方向一致、
没有"整块屋顶被误判"或"整片地面全黑"。

## 7. 已知限制

- **薄壳自阴影**：合成场景里 1.2 米厚的薄板，顶面在特定角度会出现一块楔形暗斑。
  法线偏移按纹素给，薄壳的厚度接近偏移量时压不住；真实厂区里还没复现，先记录。
- **背光面重复变暗**：深度图会把背光面判成"被遮"，但那些面本来就被 N·L 压暗了，
  等于多压一次。视觉影响小（阴影强度只有 32%），要根除得按 N·L 跳过。
- **无级联**：单张 2048 深度图覆盖全场景，远景纹素粗。600 米厂区目前可接受，
  更大场景需要 CSM。
- **静态视锥**：包围盒变化时才重算，场景静止时没有开销；但每帧调用 `setBounds`
  也不贵（不扫顶点），后续可以按需接上。
