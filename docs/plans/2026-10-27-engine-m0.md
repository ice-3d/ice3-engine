> Document ID: ICE3-ENG-PLAN-001
>
> Status: Implemented
>
> Owner: ICE3 Engine maintainers

> **面向代理工作者的说明：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 按任务逐项实施本计划。使用复选框（`- [ ]`）跟踪进度。

> **完成说明（2026-10-27）：** M0 已实施并验证。初始交付后，用户批准为示例使用 Webpack、平滑阻尼轨道输入、平面无光照材质、可选的高对比度几何边缘，并从示例中移除世界空间探测标签。本文档仍为历史实施计划；`README.md`、`docs/api/m0.md` 和 M0 设计规范描述已验收的最终行为。

**目标：** 构建一个可运行的 ICE3 M0 垂直切片，包含一个 3D 场景、分层 2D 合成、共享输入路由、显式生命周期管理和浏览器级验证。

**架构：** 使用包含四个包的 npm workspace：纯核心模型、渲染器契约及 WebGL2 后端、runtime/合成器，以及一个公共入口包。按依赖顺序开发，将所有浏览器和 GPU 访问保持在 core 包之外，然后通过一个示例集成各部分。

**技术栈：** Node.js `24.22.1` LTS、npm `>=11`、TypeScript `7.0.2`、Node.js 内置测试运行器、`expect`、`tsx`、Playwright `1.64.1`、Webpack `5.112.2`、原生 WebGL2。

**规范：** `docs/specs/2026-10-27-engine-m0-design.md`

## 全局约束

- 公共消费方只从 `ice3` 导入；内部包路径为私有。
- `@ice3/core` 没有 runtime 依赖，且不得引用 DOM、Canvas、GPU、同级包或公共总括包。
- 依赖方向为 `@ice3/core` ← `@ice3/renderer` ← `@ice3/runtime` ← `ice3`。
- M0 使用 ESM 和生成的 TypeScript 声明；CJS 和 UMD 不属于 M0。
- 浏览器后端仅使用 WebGL2，不提供 WebGL1 回退。
- 渲染器不创建公共 GPU 对象；外部 API 使用语义 ID 和 ICE 自有类型。
- 公共事件使用 `on`、`off` 和 `once`；`off` 按原始函数引用匹配。
- 每个可序列化对象均使用形如 `ice3:TypeName` 的规范类型 ID。
- M0 示例运行在端口 `8103`，Playwright 从不复用现有服务器。
- 每份文档、注释、示例、标识符、包名和目录名均遵循 ICE3 命名与法律约束。
- M0 不添加第三方 runtime 依赖。
- 渲染器、runtime 和示例在当前的 Chromium 与 WebKit 中测试。根据明确的用户范围决定，Firefox 被排除。
- M0 不添加加载、LOD、实例化、工业语义、Agent 集成、资产工具或后处理。

## 审查重点

- WebGL2 不可用，或初始化后 GPU 上下文丢失：初始化必须可预期地失败，或者引擎必须发出恢复事件且不产生重复监听器。
- 两个节点或图层声明同一身份：第二次注册必须被拒绝，且不得破坏 selection 或锚点。
- 指针从 2D 控件开始并跨越到 3D 视口：原目标在释放前保持捕获。
- 世界标签可见时容器尺寸调整或 DPR 变化：标签仍应位于其投影节点一个 CSS 像素范围内。
- 引擎反复启动、停止、销毁和重建：销毁后不得残留帧请求、监听器、GPU 句柄或 overlay canvas。

  once<T>(type: string, listener: (event: ICEEvent<T>) => void): this;

describe('core math', () => {

    const first = () => calls.push('first');
    const second = () => calls.push('second');
    events.on('change', first).on('change', second);
    events.trigger('change');
    events.off('change', first);

    expect(calls).toEqual(['first', 'second', 'second']);
