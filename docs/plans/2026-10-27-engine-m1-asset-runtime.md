# ICE3 Engine M1 Asset Runtime Implementation Plan

> Document ID: ICE3-ENG-PLAN-002
>
> Status: Implemented
>
> Owner: ICE3 Engine maintainers

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Load ICE3 Prepared GLB Profile v1 assets in the browser without a source-format or geometry-conversion pipeline, render prepared triangle and edge buffers, and release their resources safely.

**Architecture:** Add a narrow `@ice3/assets` profile reader, generalize core geometry and node transforms, replace box-only GPU storage with cached indexed geometry buffers, and add a runtime asset loader on top. The loader consumes only profile-marked GLB generated by `ice3-toolchain`.

**Tech Stack:** Node.js 24 LTS, TypeScript 7, ESM, Webpack 5, Node.js built-in test runner, `expect`, `tsx`, Playwright 1.64, native WebGL2.

**Spec:** `docs/specs/2026-10-27-engine-m1-asset-design.md`

**Prerequisite plan:** [ICE3 Toolchain M1 GLB Pipeline Plan](https://github.com/ice-3d/ice3-toolchain/blob/main/docs/plans/2026-10-27-toolchain-m1-glb-pipeline.md)

## Global Constraints

- Public consumers import only from `ice3`.
- `@ice3/core` remains free of DOM, Canvas, GPU, filesystem, and sibling-package dependencies.
- Dependency direction becomes `@ice3/core` ← `@ice3/assets` ← `@ice3/runtime`, with renderer remaining dependent only on core.
- Runtime accepts only ICE3 Prepared GLB Profile v1.
- Runtime performs no source-format adaptation, triangulation, unit conversion, matrix decomposition, mesh merging, or edge generation.
- One JSON chunk and one BIN chunk are allowed in the profile.
- Jobs use `matrix` only; runtime does not convert quaternion TRS.
- Appearance remains flat; imported materials use base color and optional edge color.
- Animation, skins, Morph targets, textures, images, cameras, lights, sparse accessors, and required extensions are rejected.
- Context loss, abort, duplicate IDs, malformed offsets, and disposal must produce deterministic diagnostics.
- Chromium and WebKit are the browser matrix. Firefox remains excluded.
- Every behavior change follows RED-GREEN-REFACTOR and merges to `main` only after `npm run verify`.

## Review Focus

- A GLB profile has a valid header but an accessor extending past the BIN chunk: loading fails without typed-array out-of-bounds access.
- A loaded asset node has a matrix and quaternion position/rotation fields from an external tool: matrix identity wins and no conversion occurs.
- A triangle primitive also has a line primitive for edges: they become one ICE mesh with prepared triangle and edge indices.
- Two loaded assets reuse a URL concurrently: they share immutable bytes but expose independent scene objects.
- `AbortSignal` fires during fetch: no scene, cache entry, or GPU upload remains for that request.
- `dispose()` is called twice: scene cleanup and renderer references are released exactly once.
